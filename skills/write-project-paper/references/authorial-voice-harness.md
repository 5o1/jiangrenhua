# 研究者叙述视角：检查而非代词配额

本规则只用于研究论文、阶段报告等需要交代研究责任的文本。技术手册或客观的接口说明不必强行改成第一人称。

1. 写作或修订时，先给段落标记论证动作：背景与前人工作、研究设计/方法选择、观察结果、解释/限制。研究者做出的选择和解释通常由“我们”“本研究”或“本文”承担；引用前人的发现须归属于原作者。结果本身和系统行为可以由数据、物体或模块作主语。
2. 对 HTML 论文运行 `scripts/audit_paper.py`。其中 `authorial_voice` 只列出缺少显式研究者主语但含设计/解释线索的段落，并展示分节覆盖情况。候选段落是人工审查队列，不是错误清单；代词数不是合格阈值。
3. 在第四轮复审记录中逐条处理候选段落：标明段落的论证动作、实际责任者、修改结果，或说明为何保留对象主语。特别复核摘要、方法取舍、结果解读、讨论和局限。将最终仍保留的候选写入论文旁的 JSON 文件：`{"retained_candidates":[{"fingerprint":"审计输出中的16位指纹","reason":"保留对象主语的具体原因"}]}`。再以 `--voice-review <该文件>` 运行审计；遗漏候选和正文修改后过期的指纹都会使门禁失败。JSON 仅保存最终保留项；已改写而不再出现的候选无需列入。
4. 不因追求“我们”而虚构已完成实验；“我们计划”“我们观察到”“我们推断”必须与证据状态一致。避免机械地把每句都改成“本研究”。

这套流程借鉴 [Vale 的 prose linting](https://docs.vale.sh/) 所强调的外部可重复检查，以及学术文章 [rhetorical moves 标注研究](https://aclanthology.org/W19-4514/) 对段落功能的划分。[MLA 的第一人称建议](https://style.mla.org/using-i/) 也把第一人称视为按修辞目的选用的工具，而非统一配额。自动匹配无法可靠判定中文句子的语义责任者，所以最终裁定必须由通读原文和证据的复审完成。
