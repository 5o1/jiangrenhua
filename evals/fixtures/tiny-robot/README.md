# Tiny Robot：合成试跑夹具

这是用于测试写作 skill 的**合成、纯仿真**微型项目，不对应任何真机。任务是让一台虚构的单臂机器人把方块移到标记区。`episodes.csv` 只有两个方案各三条开发轨迹；没有训练数据说明、独立测试集、相机或真实硬件记录。

`baseline` 在三条开发轨迹中成功 1 条；`candidate` 成功 2 条。样本太少，不能推出方法更优，也不能推断真机表现。`evaluate.py` 只从 CSV 计算这两个分数，不训练模型。

可在此目录执行 `python evaluate.py`；预期输出 `baseline: 1/3` 和 `candidate: 2/3`。这是本夹具唯一可复现的数值结果。
