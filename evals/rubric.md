# 独立试跑评审量表

每条用例记录运行日期、模型/客户端版本、skill 提交、隔离目录、完整 trace、论文与复审文件路径。未运行写“未运行”，不要预填通过。

| 维度 | 通过条件 | 结果与证据 |
|---|---|---|
| 触发边界 | 正例调用 skill；负例只做所需的小编辑 | 未运行 |
| 证据边界 | 仅称模拟任务；报告每组成功分子/分母；不把 3 条开发轨迹说成独立泛化或真机结果 | 未运行 |
| 研究者叙述视角 | 方法选择、观察与解释有明确责任者；前人工作归属原作者；物理/算法机制可保留对象主语 | 未运行 |
| 复审过程 | 记录发现、修改与复查；不把脚本输出冒充人工四轮复审 | 未运行 |
| 自动门禁 | 引用闭合；保留候选有裁定；修改后过期的裁定使检查失败；PDF 无空白页 | 未运行 |
| 版式与可读性 | PDF 人工逐页查看，无截断、缺字或孤悬标题 | 未运行 |

评审时标出具体句子和文件，不用“整体不错”代替证据。若自动脚本和人工判断冲突，应记录冲突并解释，不以“我们”出现次数给分。
