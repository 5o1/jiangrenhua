# 干净上下文试跑

这里保存的是**尚待执行**的端到端用例，不是已经通过的成绩。每次试跑都应从新的 Codex 会话和隔离的工作目录开始，只提供本仓库的 skill、`fixtures/tiny-robot/` 的原始文件与 `prompts.csv` 中的一条请求；不要提供已写好的论文、预期答案或 Panthera 的历史对话。不要把生成物写回 fixture。

先测试显式调用，再测试隐式调用、证据不足和负例。使用 `codex exec --json` 或等效的独立会话保存完整执行轨迹与生成物；若允许写入，仅给予隔离目录的写权限。逐项填写 `rubric.md`，记录失败段落和证据，然后才决定是否修改 skill。确定性脚本测试不能替代这一步。

本仓库当前**没有**完成上述独立 agent 试跑；`prompts.csv` 和 fixture 是为后续复现准备的。若试跑会消耗模型额度或需要额外权限，先取得相应授权。
